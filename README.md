Kickoff
=======

A HumHub module for running football prediction games (Tippspiel). Built
initially for the FIFA World Cup 2026, with a pluggable architecture for
additional competitions (other tournaments, national leagues, internal
company tournaments).

Members place tips on match results and bonus bets (winner, top scorer, group
winners) and compete on a shared leaderboard. Match data is pulled from
configurable adapters (football-data.org, manual entry, sandbox mock).

See [docs/CONCEPT.md](docs/CONCEPT.md) for the full design.

Requirements
------------

- HumHub 1.17 or later
- PHP 8.1 or later
